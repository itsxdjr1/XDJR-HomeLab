## Overview

I (Gemini wrote the code) built an Android application that communicates with the HPE iLO 4 Redfish API on my ProLiant DL120 Gen9.

The app gives me a simple way to remotely manage the server from my phone. Really helps save on power and cost, gives me a way to turn my server on and off like that. 

## Features

- Check server status
- Power the server on
- Force the server off
- Check whether the Proxmox host is reachable

## What I Learned

I didn't really learn much from this besides what Redfish is and the APIs that are used to shutdown and turn on the server. This was more of a cool practical idea I had for the server. I switched to Android from iPhone and was finally able to create my own app.
