# Proxmox

## Overview

I use Proxmox VE as the main virtualization platform in my homelab, works very nicely on these enterprise servers.

My primary host is an HPE ProLiant DL120 Gen9, with a Lenovo ThinkServer RS140 used as a secondary host for smaller services and testing.

## What I Use It For

- Windows and Linux virtual machines
- Graylog
- NAS storage, TrueNas + a File Browser
- Internal web services
- Testing and troubleshooting

## What I Learned

- VM deployment and resource allocation
- Virtual networking
- Linux administration
- Server hardware troubleshooting
- Managing multiple hosts
